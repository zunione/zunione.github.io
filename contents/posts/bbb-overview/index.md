# BeagleBone Black 핀아웃 다이어그램 설명

## 전체 구성 개요

BeagleBone Black에는 **두 개의 핀 헤더**가 있습니다.
- **P9** : 보드를 사진과 같이 5V 플러그가 위쪽을 향하도록 놓았을 때 **왼쪽** 헤더
- **P8** : **오른쪽** 헤더

각 헤더는 핀 번호가 1번부터 시작하며, 양쪽 열로 나뉘어져 있습니다.

---

## 핀 종류별 범례 (Legend) 설명

### 🔴 빨간색 — Power, Ground, Reset (전원 및 접지)

전원 공급 및 접지에 사용되는 핀들입니다.

| 핀 기능 | 설명 |
|---|---|
| `DGND` | 디지털 접지 (0V 기준선) |
| `VDD 3.3V` | 3.3V 전원 공급 |
| `VDD 5V` | 5V 전원 공급 |
| `SYS 5V` | 시스템 5V (USB 경유 공급) |
| `PWR_BUT` | 전원 버튼 |
| `SYS_RESET` | 시스템 리셋 핀 |
| `VDD_ADC` | **1.8V** 아날로그 기준 전압 (ADC용) |
| `GND_ADC` | ADC 전용 접지 |

> ⚠️ `VDD_ADC`는 **1.8V** 공급 핀으로, 아날로그 입력 기준 전압으로 사용됩니다.

---

### 🟢 초록색 — Digital GPIO Pins (디지털 범용 입출력)

`GPIO_XX` 형태로 표시된 **범용 디지털 입출력 핀**들입니다.

- HIGH(3.3V) / LOW(0V) 신호를 읽거나 출력할 수 있습니다.
- 일부 초록색 핀은 **UART 시리얼 통신** 기능도 겸합니다.
  - 예: `UART4_RXD`, `UART4_TXD`, `UART1_TXD`, `UART1_RXD`

---

### 🟣 보라색 — PWM Output (아날로그 유사 출력)

**PWM(Pulse Width Modulation)** 핀으로, **0 ~ 3.3V 범위의 아날로그 출력을 시뮬레이션**할 수 있습니다.

| 핀 예시 |
|---|
| `EHRPWM1A`, `EHRPWM1B` (P9) |
| `EHRPWM2A`, `EHRPWM2B` (P8) |
| `ECAPWM0` (P9) |

> LED 밝기 조절, 모터 속도 제어 등에 활용합니다.

---

### 🔵 하늘색 — 1.8V Analog Inputs (아날로그 입력)

**ADC(아날로그-디지털 변환) 핀**으로, 아날로그 전압을 디지털 값으로 읽습니다.

| 핀 | 위치 |
|---|---|
| `AIN0` ~ `AIN6` | P9 헤더 33~40번 핀 |

> ⚠️ **중요 주의사항**
> - 입력 전압 범위: **0 ~ 1.8V**
> - **1.8V를 초과하는 전압을 절대 인가하지 마세요.** 핀이 손상됩니다.
> - 아날로그 입력 사용 시, **P9-32 핀 (VDD_ADC, 1.8V)** 을 기준 전압으로, **P9-34 핀 (GND_ADC)** 을 접지로 반드시 사용하세요.

---

### 🟠 연한 주황색 — Shared I2C Bus (I2C 통신)

**I2C 프로토콜** 통신에 사용되는 핀들입니다.

| 핀 | 역할 |
|---|---|
| `I2C2_SCL` (P9-19) | 클럭 신호 |
| `I2C2_SDA` (P9-20) | 데이터 신호 |

> 센서, OLED 디스플레이, EEPROM 등 I2C 디바이스 연결에 사용합니다.

---

### 🟧 진한 주황색 — Reconfigurable Digital / LCD (LCD 및 재설정 가능 핀)

주로 **LCD 스크린 연결**에 사용되는 핀들로, P8 헤더의 많은 부분을 차지합니다.

| 핀 예시 |
|---|
| `LCD_DATA0` ~ `LCD_DATA15` |
| `LCD_VSYNC`, `LCD_HSYNC`, `LCD_PCLK`, `LCD_AC_BIAS` |

> LCD를 사용하지 않는 경우, 일부 핀은 일반 GPIO로 재설정하여 활용할 수 있습니다.

---

## 정리 요약표

| 색상 | 기능 | 전압 범위 | 주요 용도 |
|---|---|---|---|
| 🔴 빨간색 | 전원 / 접지 / 리셋 | 1.8V / 3.3V / 5V | 전원 공급, 접지 연결 |
| 🟢 초록색 | 디지털 GPIO + UART | 0 ~ 3.3V | 디지털 입출력, 시리얼 통신 |
| 🟣 보라색 | PWM 출력 | 0 ~ 3.3V | 아날로그 유사 출력, 모터/LED 제어 |
| 🔵 하늘색 | 아날로그 입력 (AIN) | **0 ~ 1.8V** | 센서 아날로그 신호 읽기 |
| 🟠 연주황색 | I2C 버스 | 3.3V | I2C 디바이스 통신 |
| 🟧 진주황색 | LCD / 재설정 가능 | 3.3V | LCD 패널 연결, GPIO 재사용 |

---

> 💡 **핵심 주의사항 재강조**
> 아날로그 입력 핀(AIN)에는 반드시 **1.8V 이하**의 전압만 인가해야 합니다. 그 이상의 전압은 **보드 손상**을 초래할 수 있습니다.
